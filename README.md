# שותף לערבית

אפליקציית רשת לתרגול **ערבית מדוברת (פלסטינית־ירושלמית)** ברמת מתחילים — דיבור ושמיעה בלבד, בלי קריאה וכתיבה בערבית.

- לוחצים על המיקרופון ומדברים; השותף (Gemini של גוגל) שומע את ההקלטה עצמה.
- הכל מוצג בתעתיק עברי + תרגום, עם תיקון טעויות והסבר בעברית.
- השותף עונה בקול, בלהג ירושלמי, לאט וברור.
- תרחישים: היכרות, בית קפה, שוק, משפחה, מונית ועוד. סיכום טעויות ומילים בסוף כל שיחה.

## הפעלה
האתר: https://arabic-practice-virid.vercel.app/
בפעם הראשונה מדביקים מפתח Gemini חינמי (https://aistudio.google.com/apikey). המפתח נשמר רק בדפדפן.
בטלפון: "הוסף למסך הבית" כדי לפתוח כמו אפליקציה.

## גרסאות
- **0.1.0** — גרסה ראשונה: 10 תרחישי שיחה, הקלטה ושליחת קול ל-Gemini, תעתיק עברי, תיקונים (אחרי כל משפט או בסיכום), רמז, השמעה רגילה/איטית, סיכום שיחה עם טעויות ומילים, הגדרות קול ומהירות.
